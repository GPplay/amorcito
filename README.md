# Amorcito ❤️ | Nuestra Historia de Amor

Página web romántica e interactiva dedicada al amor de mi vida.

## ✨ Características Especiales
- **Galería de Recuerdos:** Colección completa de nuestras fotos favoritas con efecto polaroid, ampliación en pantalla completa (Lightbox) y navegación táctil / teclado.
- **Bitácora de Viajes por Colombia:** Mapa interactivo con los 32 departamentos y Bogotá D.C.
  - Marcadores y corazones pulsantes en **Bogotá D.C.** y **Bolívar (Cartagena)** como lugares ya visitados juntos.
  - Barra de progreso de aventuras compartidas.
  - Información y notas románticas para cada departamento.
- **Contador de Amor en Tiempo Real:** Días, horas, minutos y segundos compartidos juntos, con opción de ajustar la fecha de aniversario.
- **Lluvia de Corazones y Pétalos:** Animación de fondo suave con botón flotante para activar o pausar.
- **Música Romántica:** Botón flotante para reproducir una melodía romántica acústica o cualquier canción personalizada.
- **Diseño Responsivo y Elegante:** Optimizado para teléfonos inteligentes, tablets y computadoras.
